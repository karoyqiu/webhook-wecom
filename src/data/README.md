# ntfy emoji data

`ntfy-emojis.json` contains all 1,855 entries from
[`binwiederhier/ntfy` mail/mailer_emoji_map.json](https://github.com/binwiederhier/ntfy/blob/addb2488ee830db465844685d09f30977c6a207b/mail/mailer_emoji_map.json),
pinned at `addb2488ee830db465844685d09f30977c6a207b` (retrieved 2026-11-25).
Only JSON whitespace was removed. Shortcodes and Unicode strings are unchanged.

Upstream license: Apache-2.0, reproduced in `ntfy-LICENSE`. No runtime download.
To update, download that file from a reviewed pinned commit, compact JSON without
changing values, and rerun HTTP tag/priority tests. No dependency added.

The same map is generated by upstream `scripts/emoji-convert.sh` for
`web/src/app/emojisMapped.js`; all entries were checked equal to the mail map.
Original dataset: [github/gemoji](https://github.com/github/gemoji), copyright
2019 GitHub, Inc., MIT license reproduced in `gemoji-LICENSE` from commit
`fadaeaf1f1a9be82b321316a6c5502e43138b2f6`.
